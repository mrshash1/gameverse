## 🚀 اجرا

هیچ نصب و بیلدی لازم نیست:

```bash
# هر سرور استاتیکی:
python3 -m http.server 8080
# → http://localhost:8080
```

یا کافیست ریپو را روی GitHub Pages بگذارید (فایل `index.html` در ریشه است).

## 🌍 بازی آنلاین با دوستان — چطور؟

۱. یکی «ساخت اتاق» می‌زند → کد ۵ حرفی می‌گیرد (مثلاً `XK8KM`)
۲. کد یا **لینک دعوت** را برای دوستانش می‌فرستد (تلگرام، واتساپ…)
۳. دوستان لینک را باز می‌کنند → هر دو/همه داخل یک اتاق‌اند
۴. میزبان بازی و حالت را انتخاب می‌کند → شروع!
۵. همه‌چیز real-time است: حرکت‌ها، گپ، آماده‌بودن، نتیجه

**زیر ساخت:** WebRTC مستقیم بین مرورگرها (کتابخانه‌ی Trystero با رله‌های Nostr که در فایل `vendor/` لوکال شده). هیچ سروری لازم نیست و از فیلترینگ هم مستقل است. بازی هم‌زمان (online presence)، لیست دوستان آنلاین و صف بازی سریع (Quick Play) هم از همین راه کار می‌کنند.

## ☁️ اکانت مشترک بین دستگاه‌ها

- اکانت‌ها همیشه **لوکال و رمزدار** ذخیره می‌شوند (پسورد به‌صورت هش نمکی SHA-256 — هیچ‌وقت plaintext ذخیره/ارسال نمی‌شود).
- اگر سرویس ابری در دسترس باشد (jsonblob یا Endpoint دلخواه)، ثبت‌نام/ورود/جدول قهرمانان بین همه‌ی دستگاه‌ها **مشترک** می‌شود.
- برای بک‌اند اختصاصیِ رایگان، `docs/worker.js` را روی Cloudflare Workers دیپلای کنید و آدرسش را در **تنظیمات → مدیریت → آدرس بک‌اند** بگذارید.
- وقتی ابری در دسترس نباشد، همه‌چیز آفلاین کار می‌کند و رابط کاربری صادقانه وضعیت را نشان می‌دهد (بدون تقلب!).

## 🧩 افزودن بازی جدید (پلاگین)

فقط یک فایل بسازید: `games/mygame/game.js`

```js
PV.registry.register({
  id:'mygame', cats:['board'], players:[2,2], modes:['solo','online'],
  factory: (ctx)=> {
    // ctx.root, ctx.mode, ctx.send/on (P2P), ctx.finish({res:'w'})
    return { init(){}, start(){}, destroy(){} };
  }
});
```

متادیتا در `js/registry.js` اضافه می‌شود — دسته‌بندی‌ها hard-code نیستند و از پنل مدیریت هم قابل توسعه‌اند.

## 📁 ساختار

```
index.html          ← پوسته‌ی SPA
css/                ← توکن‌های طراحی (روشن/دارک) + کامپوننت‌ها + صفحه‌ها + بازی‌ها
js/                 ← i18n، util، صدا، visuals (SVG)، store، cloud، net (P2P)، sdk، ui، screens/، app
games/<id>/game.js  ← ماژول هر بازی (lazy-load)
vendor/trystero-nostr.mjs  ← WebRTC P2P (لوکال‌شده، بدون CDN)
fonts/              ← وزیرمتن FD (اعداد فارسی)
docs/               ← راهنما، معماری، worker.js، دیپلوی
```

## ⚠️ محدودیت‌ها (صادقانه)

- **مسابقه‌های P2P** فقط وقتی هر دو طرف آنلاین‌اند کار می‌کند (بازی هم‌زمان — نه server browser دائمی).
- **اکانت ابری** به در دسترس بودن سرویس ابری وابسته است؛ در نبودش، اکانت روی هر دستگاه جدا می‌ماند (با کد همگام‌سازی قابل انتقال است: پروفایل → کد همگام‌سازی).
- دشمنِ تقلب نیستیم: منطق بازی روی کلاینت اجرا می‌شود؛ برای anti-cheat واقعی سرور لازم است (مسیر ارتقا در docs).
- حداکثر توصیه‌شده: ۸ نفر در اتاق، ۲ تا ۸ نفر در کوئیز/واکنش‌سنج.
