# 🎮 گیماورس (GameVerse) — کهکشان بازی‌های اجتماعی

پلتفرم اجتماعی چندبازیِ کامل در مرورگر — الهام‌گرفته از Roblox و Plato ولی با هویت بصری مستقل.
**۷ بازی کامل و قابل‌بازی** + دوستان + دستاورد + رده‌بندی + جوایز روزانه + اتاق‌های بازی + پنل مدیریت — همه در یک سایت استاتیک **بدون نیاز به نصب یا بیلد**.

> این نسخه یک **نمونهٔ اولیهٔ کامل (Prototype)** است: تمام منطق سمت کلاینت اجرا می‌شود و داده‌ها در `localStorage` ذخیره می‌شوند. معماری کامل بک‌اند واقعی در [`docs/BACKEND.md`](docs/BACKEND.md) طراحی شده است.

## ✨ امکانات پلتفرم

- **خانهٔ داینامیک:** هیرو، بازی ویژه، ردیف‌های «محبوب / تازه / پیشنهاد برای تو / دوستان در حال بازی / سریع / رقابتی / علاقه‌مندی» — همه از رجیستری بازی‌ها ساخته می‌شوند (هاردکد نیستند)
- **کشف:** جست‌وجو، فیلتر دسته (داینامیک)، مرتب‌سازی، صفحهٔ جزئیات هر بازی با رده‌بندی اختصاصی
- **اجتماعی:** دوستان (درخواست/پذیرش/حذف/مسدودسازی)، وضعیت آنلاین، پیشنهاد دوست، مرکز اعلان‌ها با دسته‌بندی
- **پیشرفت:** XP و سطح، ۱۶ دستاورد با امتیاز، بج و عنوان و قاب آواتار (قابل خرید با سکه)
- **رقابتی:** رده‌بندی هفتگی/کلی/دوستان + رده‌بندی هر بازی + رده‌های رقابتی (برنز تا استاد) با ELO سبک
- **جوایز:** پاداش ورود روزانه با زنجیره، ۳ مأموریت روزانه + ۳ هفتگی، سکهٔ مجازی
- **اتاق‌ها:** ساخت/پیوستن با کد، لینک دعوت واقعی (Deep Link)، میزبان با اختیارات کامل، بازیکنان نمایشیِ برچسب‌دار
- **مدیریت:** آنالیتیکس واقعی از دادهٔ محلی (DAU، مسابقه‌ها، بازی‌های محبوب، فعالیت هفتگی)، مدیریت کاربر/بازی/اتاق/گزارش
- **تجربه:** تم تاریک/روشن، فارسی RTL کامل، صدا با WebAudio (بدون فایل)، تمام‌صفحه، مکث، شمارندهٔ امتیاز، اشتراک‌گذاری نتیجه، PWA (نصب روی موبایل)، ریسپانسیو موبایل‌اول با تب‌بار اختصاصی

## 🏗️ معماری در یک نگاه

```
index.html                 ← پوستهٔ اپ (تنها صفحهٔ HTML)
├─ css/
│  ├─ tokens.css           ← دیزاین‌سیستم (توکن‌ها + کامپوننت‌ها + تم روشن/تاریک)
│  ├─ pages.css            ← پوسته، خانه، کشف، جزئیات
│  └─ modules.css          ← بازی، لابی، پروفایل، اجتماعی، مدیریت
└─ js/
   ├─ app.js               ← بوت، نوبار، تب‌بار، آن‌بوردینگ، جست‌وجوی سراسری
   ├─ app-bridge.js        ← پل صفحات با پوسته (بدون وابستگی حلقوی)
   ├─ core/                ← utils، bus (رویدادها)، store (localStorage)،
   │                          router (هش)، sound (WebAudio)، i18n، ui (کامپوننت‌ها)
   ├─ data/registry.js     ← ⭐ رجیستری مرکزی بازی‌ها + دسته‌های داینامیک
   ├─ api/                 ← Mock API (قابل‌تعویض با سرور): core، mock-api، mock-api-social
   ├─ games/sdk.js         ← ⭐ قرارداد استاندارد بازی + ضدتقلب
   ├─ games/*.js           ← ۷ ماژول بازی (lazy import — code splitting واقعی)
   └─ pages/*.js           ← ۱۴ صفحه (hash router)
```

## ➕ افزودن بازی جدید (فقط ۲ قدم!)

1. یک مدخل به `GAMES` در `js/data/registry.js` اضافه کن:
```js
{
  id: 'my-game', title: 'بازی من', emoji: '🎲',
  categories: ['casual'], players: '۱ نفر', playTime: '۲ دقیقه',
  short: 'یک جملهٔ کوتاه', description: 'توضیح کامل…',
  rating: 4.5, tags: ['برچسب'], gradient: ['#7c3aed', '#06b6d4'],
  modes: [{ id: 'solo', label: 'تک‌نفره' }],
  seedPlays: 0, addedAt: '2026-09-11',
}
```
2. فایل `js/games/my-game.js` با این قرارداد بساز:
```js
import { registerFactory } from '../data/registry.js';

function createGame(host) {
  // host.root = ظرف DOM | host.mode | host.difficulty
  // host.sound('win') | host.setHud({score, time, note})
  // host.finish({ outcome:'win', score: 120, durationSec: 45, stats:[{label:'…',value:'…'}] })
  return { start() {}, pause() {}, resume() {}, destroy() {} };
}
registerFactory('my-game', createGame);
export default createGame;
```
همین! خانه، کشف، جزئیات، رده‌بندی، مأموریت‌ها، دستاوردها و پنل مدیریت **خودکار** بازی جدید را نشان می‌دهند.
راهنمای کامل با مثال: [`docs/ADD-NEW-GAME.md`](docs/ADD-NEW-GAME.md)
