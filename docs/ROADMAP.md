# 🗺️ نقشهٔ راه — بیش از ۱۰۰ ایدهٔ آینده

دسته‌بندی‌شده در ۳ سطح تا از «حجم بی‌دلیل» جلوگیری شود:
- **سطح ۱ — پیشرفته (قدم بعدی منطقی):** ارزش بالا، با معماری فعلی هم‌خوان
- **سطح ۲ — اختیاری:** وقتی بک‌اند و جمعیت واقعی arrive شد
- **سطح ۳ — بلندمدت:** اکوسیستم کامل

## سطح ۱ — پیشرفته (۲۵ مورد)
1. Service Worker برای آفلاین کامل (PWA نصب‌پذیر واقعی)
2. چندزبانی کامل (en / ar + سوئیچ زنده + فایل‌های locale)
3. تم سوم «نئون» + تم روشنِ زنانه + تم فصلی
4. چت سادهٔ اتاق (محلی/آمادهٔ WS)
5. تورنومت ۸ نفرهٔ خودکار با براکت روی بازی‌های حریف‌دار
6. Matchmaking خودکار با بازهٔ رتبه
7. رتبهٔ جداگانه برای هر بازی (به‌جای رتبهٔ سراسری)
8. پروفایل عمومی قابل اشتراک (اسکرین‌شات کارت بازیکن)
9. آمار پیشرفتهٔ هر بازی (هیت‌مپ حرکت‌ها در دوز و چهار ردیف)
10. چالش دوستان با لینک («من ۸۵۰ زدم، تو چی؟»)
11. یادآور پاداش روزانه با Notification API
12. مأموریت‌های رویدادی (آخر هفتهٔ دوبرابر XP)
13. جعبهٔ شانس روزانه با انیمیشن
14. فروشگاه آیتم‌های مصرفی (بوست XP یک‌ساعته)
15. صندلی تماشاگر برای اتاق‌ها (replay زندهٔ حرکت‌ها)
16. سیستم گزارش داخل بازی (بدون خروج از صفحه)
17. حالت تمرینی با راهنمای مرحله‌به‌مرحلهٔ هر بازی
18. دستاورد مخفی (Surprise achievements)
19. صفحهٔ «دستاورد نزدیک» (۲ مورد مانده)
20. بازی حدس کلمهٔ روزانهٔ مشترک (همه یک کلمه در روز)
21. رقابت هفتگی دوستان با جام مجازی
22. خلاصهٔ هفتگی ایمیلی/داخل‌برنامه («این هفته ۱۲ بازی، ۷ برد»)
23. کنترل لمسی بهتر برای موبایل (سوایپ در حافظه، لرزش haptic)
24. حالت کم‌مصرف (بدون انیمیشن برای گوشی‌های ضعیف)
25. پشتیبان‌گیری خودکار در فایل + بازیابی با QR

## سطح ۲ — اختیاری (۴۰ مورد؛ نیازمند بک‌اند)
26. اکانت واقعی (رمز/OAuth) با همگام‌سازی چنددستگاه
27. چت خصوصی و گروهی + ریپلای/ری‌اکشن
28. حضور زندهٔ واقعی (WebSocket heartbeat)
29. بازی زندهٔ هم‌زمان در اتاق‌ها (دوز/چهار ردیف sync)
30. تورنومت‌های ۱۶/۳۲ نفره با جدول حذفی
31. فصل‌های رقابتی (Season) با ریست نرم رتبه
32. بتل‌پس مجازی (رایگان) با ۳۰ پله
33. کلن/گیلد با عضویت، توضیحات و جنگ امتیاز
34. جدول رده‌بندی کلن‌ها
35. سیستم دوست‌یابی هوشمند (هم‌سطح + هم‌زمان آنلاین)
36. بازپخش مسابقه (Replay) قابل اشتراک
37. استریم حالت تماشا با تأخیر صفر برای اتاق‌ها
38. پروفایل عمومی با دیوار نظرات
39. دنبال‌کردن بازیکنان (Follow جدا از دوستی)
40. امتیازدهی و نظر به بازی‌ها (★ + متن)
41. صفحهٔ سازندهٔ بازی (Creator Profile) + آمار اجرا
42. UGC: بارگذاری بازی‌های جامعه (قرارداد SDK فعلی)
43. ویرایشگر بازی بدون کد ( drag&drop برای انواع الگو)
44. مارکت‌پلیس آیتم‌ها با کمیسیون سازنده
45. NFT-free آیتم‌های کم‌یاب با شماره سریال داخلی
46. تجارت/هدیه دادن آیتم بین بازیکنان
47. آواتار سازنده (لایه‌های ترکیبی به‌جای ایموجی)
48. قاب و عنوان فصلی با انقضا
49. جامدات رتبه‌ای (تیشرت دیجیتال پروفایل)
50. سیستم گزارش و دادگاه جامعه (Jury)
51. Shadow-ban و سهمیهٔ پنالتی ضدتقلبی
52. Verify دو مرحله‌ای + session manager
53. اعلان‌های push واقعی (VAPID)
54. دعوت گروهی ۴ نفره با لینک واحد
55. ربات‌های هوشمند LLM برای حریف گفتگویی
56. ترجمهٔ خودکار چت چندزبانه
57. حالت خانواده (کنترل والدین + زمان بازی)
58. منطقه‌بندی سرور (EU/Asia) با انتخاب latency
59. بازی بدون اینترنت با sync خودکار بعداً
60. API عمومی + کلید توسعه‌دهنده
61. Webhook برای سرورهای کامیونیتی
62. داشبورد خالق با درآمد تقسیمی
63. حمایت مالی بازیکن (حمایت‌گر با بج)
64. جشنوارهٔ بازی‌های جامعه با رأی‌گیری

## سطح ۳ — بلندمدت (۳۵+ مورد؛ اکوسیستم)
65. اپ موبایل Native (React Native/Flutter) با همان API
66. اپ دسکتاپ (Electron/Tauri)
67. کلاینت کنسولی/TV (Web TV layout)
68. صدا در اتاق‌ها (Voice channel با WebRTC)
69. ویدیو پیام کوتاه (Clip) برای لحظه‌های برد
70. هایلایت خودکار لحظات کلیدی (AI)
71. مربی هوشمند个人ی (تحلیل ضعف‌ها و تمرین پیشنهادی)
72. مسیر یادگیری «چطور حرفه‌ای شوم» برای هر بازی
73. لیدربورد جهانی واقعی با احراز هویت ضدغloyt
74. رزومهٔ بازیکن قابل‌خروجی (PDF کارت آمار)
75. scouting برای تیم‌های رقابتی (دیده‌بان استعداد)
76. لیگ‌های رسمی با جایزهٔ واقعی (کارت هدیه)
77. همکاری با استریمرها (حالت co-stream)
78. افزونهٔ مرورگر برای رقابت سریع
79. widget پروفایل برای سایت‌های دیگر
80. موتور قالب‌بازی (Game Maker کامل) با انتشار یک‌کلیکی
81. بازار قالب بازی بین سازندگان
82. سیستم ترفیع بازی‌های جامعه (Curator تیم)
83. مدیریت نسخهٔ بازی‌ها + بازگشت به نسخهٔ قبل
84. سرویس میزبانی ابری برای بازی‌های سنگین UGC
85. پرداخت واقعی (درگاه) با سکهٔ پرمیوم شفاف
86. اشتراک ویژه (بدون تبلیغ، آیتم ماهانه) — بدون pay-to-win
87. هدیهٔ روزانهٔ اسپانسری
88. برنامهٔ درآمدی سازندگان (Revenue share)
89. پیوستن با حساب کنسول (Cross-platform identity)
90. handoff بین دستگاه‌ها (از موبایل به دسکتاپ وسط مسابقه)
91. پشتیبانی دستیابی‌پذیری کامل (screen reader برای همهٔ بازی‌ها، کنترل تک‌دکمه)
92. بازی برای نابینایان (نسخهٔ صوتی حافظه و دوز)
93. حالت تک‌دست برای موبایل
94. رابط کاربری قابل شخصی‌سازی (چیدمان ویجت خانه)

96. پیش‌بینی churn و بازگشت بازیکن با جایزه

98. زبان‌های بیشتر (tr، ur، id…) با مشارکت جامعه
99. مودریشن خودکار چت (مدل زبانی) + فیلتر محلی

101. پلتفرم آموزشی داخل بازی (کدنویسی بازی برای نوجوانان)
102. مسابقات مدرسه‌ای/سازمانی با پنل نهاد
103. حالت پارتی آفلاین (چند نفر روی یک گوشی با صفحهٔ تقسیمی)
