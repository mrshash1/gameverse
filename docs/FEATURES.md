# ✅ امکانات فعلی — فهرست کامل (نسخهٔ ۱.۰)

همهٔ موارد زیر **واقعاً کار می‌کنند** (تست‌شده در مرورگر). داده‌ها در localStorage با Mock API قابل‌تعویض ذخیره می‌شوند.

## 🎮 بازی‌ها (۷ عنوان کامل)
- چرخهٔ کامل: انتخاب حالت/سطح → HUD زنده (امتیاز/زمان/یادداشت) → مکث/ادامه → تمام‌صفحه → پایان → صفحهٔ نتیجه → بازی دوباره/بازی بعدی
- Lazy loading واقعی هر بازی (code splitting با import() داینامیک)
- حافظه (۸ جفت، امتیاز زمان+حرکت) | آزمون دانش (۴۴ سؤال، تایمر ۱۵ ثانیه، جایزهٔ سرعت، زنجیره)
- دوز (ربات Minimax شکست‌ناپذیر + ۳ سطح + دو‌نفره) | سنگ کاغذ قیچی (ربات پیش‌بین الگو + بهترین از ۵)
- سرعت واکنش (۵ راند، جریمهٔ پرتاب زودهنگام، آمار میانگین/بهترین/بدترین)
- چهار در یک ردیف (Minimax عمق ۴ + هرس آلفا-بتا، انیمیشن سقوط، دو‌نفره)
- حدس کلمهٔ فارسی (۶۸ کلمهٔ ۵ حرفی، کیبورد فارسی با «آ» مستقل، رنگ‌بندی استاندارد با مدیریت حروف تکراری، کیبورد فیزیکی)

## 🏠 خانه و کشف
- هیرو خوش‌آمد با سلام بر اساس ساعت، چیپ‌های سطح/سکه/زنجیره/بازی، نوار XP
- «🎲 سورپرایزم کن» (بازی تصادفی) + بازی ویژهٔ امروز (قابل کنترل از پنل مدیریت)
- ۷ ردیف داینامیک از رجیستری: محبوب، تازه، پیشنهاد قاعده‌محور، دوستان در حال بازی، سریع، رقابتی، علاقه‌مندی‌ها
- کشف: جست‌وجوی زنده، فیلتر دستهٔ داینامیک با شمارنده، ۴ مرتب‌سازی، حالت خالی
- جزئیات بازی: بنر گرادیانی، متا، علاقه‌مندی، کپی لینک، «اتاق بازی»، رکورد شخصی، برترین‌های بازی، بازی‌های مشابه
- جست‌وجوی سراسری (بازی + بازیکن) با اورلی

## 👥 اجتماعی
- درخواست/پذیرش/رد/حذف/مسدودسازی دوستی؛ پذیرش خودکار شبیه‌سازی‌شدهٔ کاربران نمایشی (شفاف و برچسب‌دار)
- وضعیت حضور (آنلاین/در حال بازی/غایب/آفلاین)، پیشنهاد دوست، جست‌وجوی بازیکن
- درخواست دوستی ورودی خودکار پس از ~۴۵ ثانیه (زندگی نمایشی)
- مرکز اعلان‌ها با ۵ دسته، ناخوانده/خوانده، بج شمارنده در نوبار

## 📈 پیشرفت و رقابتی
- XP با فرمول سطح ۱۰۰×L^1.35، پاداش ارتقا (۱۰ سکه × سطح جدید)
- ۱۶ دستاورد با امتیاز و ارزیابی خودکار پس از مسابقه/اکشن اجتماعی/میزبانی
- آمار کامل: بازی/برد/باخت/تساوی/نرخ برد/زنجیره/XP/بازی محبوب + عملکرد هر بازی
- رده‌بندی: هفتگی/همه‌وقت/دوستان × XP/برد/بازی + رده‌بندی هر بازی + سکو + ردیف «شما»
- رده‌های رقابتی برنز→استاد با ELO سبک برای بازی‌های حریف‌دار

## 🎁 اقتصاد و جوایز
- سکهٔ مجازی؛ پاداش ورود روزانه با زنجیرهٔ ۷ روزه؛ ۳ مأموریت روزانه + ۳ هفتگی با پیشرفت و گرفتن جایزه
- فروشگاه: ۵ قاب آواتار + ۵ عنوان با خرید/فعال‌سازی

## 🏟️ اتاق‌ها و لابی
- ساخت اتاق (نام، بازی، حالت تفریحی/رنکد/سریع، ظرفیت ۲–۸، خصوصی با کد ۶ کاراکتری)
- پیوستن با کد یا از فهرست اتاق‌های باز؛ لینک دعوت Deep-Link واقعی (`#/room/CODE`)
- میزبان: شروع بازی، حذف بازیکن، افزودن بازیکن نمایشی (برچسب 🤖)، بستن اتاق؛ به‌روزرسانی زندهٔ صفحهٔ اتاق

## 🛠️ پنل مدیریت (نمایشی، با گیت از تنظیمات)
- نمای کلی: ۸ شاخص (DAU، مسابقات، سکهٔ صادرشده، میانگین زمان بازی و…) + نمودار ۷ روزه + محبوبیت واقعی بازی‌ها
- کاربران (مسدودسازی)، بازی‌ها (فعال/ویژه — بلافاصله در UI اعمال می‌شود)، اتاق‌ها (بستن)، گزارش‌ها (رسیدگی/رد)، داده‌ها (بازتولید دمو، پاک‌سازی کامل)

## 🎨 تجربهٔ کاربری
- فارسی RTL کامل، فونت وزیرمتن، تم تاریک پیش‌فرض + تم روشن کامل
- موبایل‌اول: تب‌بار پایین، چیدمان اختصاصی، تارگت‌های لمسی ≥۴۴px
- صدا با WebAudio (۱۱ افکت سنتزی، بدون فایل) + ولوم + قطع
- Toast، Modal، Confirm، Skeleton، Empty-state، شمارندهٔ انیمیشنی امتیاز، اسکرول افقی snapدار
- خطای سراسری با پیام دوستانه، وضعیت آنلاین مرورگر، Deep Link همهٔ صفحات، 404 اختصاصی
- PWA: manifest + آیکون + نصب روی صفحهٔ اصلی موبایل؛ خروجی JSON از داده‌ها (پشتیبان)
- ذخیرهٔ خودکار همه‌چیز در localStorage (+ نسخه‌بندی DB)
