# راهنمای کامل پلی‌ورس (برای کاربر)

## شروع سریع
1. سایت را باز کنید: `https://mrshash1.github.io/gameverse/`
2. دکمه‌ی **ورود** → تب **ثبت‌نام** → نام کاربری انگلیسی (مثل `ali_gamer`)، نام نمایشی فارسی، رمز حداقل ۶ کاراکتری.
3. اگر عجله دارید: **بازی به‌عنوان مهمان** — بدون ثبت‌نام بازی کنید (XP ثبت می‌شود ولی اکانت فقط روی همان دستگاه است).

## بازی با دوستان (آنلاین واقعی)
1. از خانه یا صفحه‌ی هر بازی: **ساخت اتاق**.
2. کد ۵ حرفی بالای اتاق را کپی کنید یا از دکمه‌ی «دعوت رفیق‌ها» لینک مستقیم بگیرید.
3. دوستتان لینک را باز می‌کند یا از خانه کد را در «کد اتاق…» وارد می‌کند.
4. هر دو **آماده** شوید (دکمه‌ی آماده) — میزبان بازی و حالت را انتخاب می‌کند و **شروع** می‌زند.
5. وسط بازی گپ و شکلک دارید. 🎯🔥

### حالت‌های بازی
| حالت | توضیح |
|---|---|
| کلاسیک | بازی استاندارد با XP |
| رنک‌دار | رنک ELO همان بازی بالا/پایین می‌شود |
| تفننی | بدون استرس، XP کمتر |
| سریع | هرکس زودتر ۳ بار ببرد برنده‌ی کل است |
| تورنمنت | ۴ نفره، نیمه‌نهایی + فینال |

### بات
اگر تنها هستید، در اتاق «+ افزودن بات» بزنید یا از صفحه‌ی بازی، حالت تک‌نفره را انتخاب کنید (۳ سطح سختی).

## پیشرفت
- **XP و سطح**: از هر بازی (برد = بیشتر). سطح‌ها در پروفایل.
- **سکه**: برد، ماموریت، دستاورد، جایزه‌ی روزانه → خرج آواتارهای جدید کن.
- **دستاورد**: ۲۰ نشان از «اولین قدم» تا «قهرمان تورنمنت».
- **ماموریت روزانه**: هر ۳ ماموریت، هر روز تهران ساعت ۰۰:۰۰ عوض می‌شوند.
- **جایزه‌ی ورود روزانه**: ۷ روز پیوسته = جایزه‌ی بزرگ.

## دوستان
- نام کاربری دقیق دوستت را در صفحه‌ی دوستان وارد کن → درخواست می‌رود.
- دوستِ آنلاین کنار اسمش نقطه‌ی سبز دارد → می‌توانی مستقیم دعوتش کنی.

## تنظیمات
- زبان: فارسی / English / العربية (تمام رابط راست‌به‌چپ یا چپ‌به‌راست می‌شود)
- تم: روشن (پیش‌فرض) / دارک
- صدا، انیمیشن، پاک‌کردن داده‌ی دستگاه

## پنل مدیریت (`#/admin`)
کد پیش‌فرض: **1234** (از فایل `js/screens/admin.js` یا بعداً از خود پنل قابل تغییر است)
- آمار کاربران/بازی‌ها
- **اطلاعیه‌ی همگانی**: بنویس و «ارسال برای همه» → همه کاربران ابری بالای سایت می‌بینند
- مدیریت دسته‌بندی‌ها و خاموش/روشن کردن هر بازی
- خروجی JSON از همه‌ی داده‌های محلی

## بک‌اند ابری اختصاصی (اختیاری، ۵ دقیقه)
برای اکانت ۱۰۰٪ مشترک بین همه:
1. یک Cloudflare Worker بساز (رایگان) و محتوای `docs/worker.js` را paste کن.
2. آدرس Worker را در پنل مدیریت → «آدرس بک‌اند سفارشی» ذخیره کن.
3. حالا ثبت‌نام/ورود/جدول قهرمانان روی همه‌ی دستگاه‌ها مشترک است.

## نکته‌ی مهم امنیتی
توکن گیت‌هابی که برای دیپلوی استفاده شد در تاریخ چت لو رفته است. هر وقت خواستی از تنظیمات گیت‌هاب → Developer settings → Tokens آن را حذف/تمدید کن.

## 🖥 نسخه ۴ — اکانت روی سرور + ادمین واقعی (mrshash)

### راه اندازی سرور در ۳ قدم
1. پوشه‌ی `server/` را کنار بقیه‌ی فایل‌ها روی گیت‌هاب آپلود کن (همان روش همیشگی).
2. در [render.com](https://render.com) با اکانت گیت‌هاب وارد شو → **New + ← Web Service** → ریپو را انتخاب کن:
   - Root Directory: `server` — Build: `npm install` — Start: `npm start` — Type: **Free**
3. آدرسی که می‌گیری (مثل `https://playverse-server.onrender.com`) را در بازی وارد کن:
   **تنظیمات ← سرور بازی ← آدرس ← تست اتصال ← ذخیره**

از این لحظه:
- ✅ همه‌ی ثبت‌نام‌ها **روی سرور** ذخیره می‌شوند (از هر دستگاهی با همان اکانت وارد شو)
- ✅ جدول قهرمانان جهانی واقعی می‌شود
- ✅ درخواست دوست از طریق سرور تحویل می‌رسد
- ✅ شمارنده‌ی «فلان نفر آنلاین» فعال می‌شود

### پنل ادمین
- با اکانت **`mrshash`** وارد شو → منوی مدیریت به‌صورت خودکار کامل باز می‌شود 👑
- **کاربران:** جستجو، هدیه‌ی XP و سکه، مسدود/رفع مسدودی، ادمین‌کردن، حذف کامل
- **جهان:** اطلاعیه‌ی همگانی (همه فوراً می‌بینند)، خاموش/روشن کردن هر بازی، آمار بازی‌ها
- اکانت `mrshash` قابل مسدودسازی/حذف نیست (محافظت‌شده)
