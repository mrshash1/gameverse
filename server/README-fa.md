# 🖥 سرور واقعی پلی‌ورس — راهنمای فارسی

این سرور، اکانت‌ها را **واقعاً روی سرور** ذخیره می‌کند:

- ✅ ثبت‌نام و ورود با رمز هش‌شده (scrypt) — رمزها هیچ‌وقت خام ذخیره نمی‌شوند
- ✅ پروفایل (XP، سکه، آمار، رنک‌ها، دوستان) بین همه‌ی دستگاه‌ها سینک می‌شود
- ✅ جدول قهرمانان جهانی واقعی
- ✅ درخواست دوست از طریق سرور
- ✅ پنل مدیریت کامل — اکانت **mrshash** خودکار ادمین می‌شود
- ✅ شمارنده‌ی «آنلاین‌ها» و رله‌ی اتاق‌ها از طریق WebSocket

> بعد از دیپلوی، فقط آدرس سرور را در **تنظیمات ← سرور بازی** وارد کن. تمام!

---

## راه ۱ — دیپلوی رایگان روی Render (پیشنهادی، ~۱۰ دقیقه)

1. فایل‌های پروژه (شامل پوشه‌ی `server/`) را در گیت‌هاب آپلود کن (همان روش کشیدن‌ورهاکردن).
2. برو به [render.com](https://render.com) و با اکانت گیت‌هاب ثبت‌نام کن.
3. **New + ← Web Service** را بزن و ریپوی `gameverse` را انتخاب کن.
4. این تنظیمات را بده:
   - **Root Directory:** `server`
   - **Runtime:** `Node`
   - **Build Command:** `npm install`
   - **Start Command:** `npm start`
   - **Instance Type:** `Free`
5. **Create Web Service** را بزن. بعد از ۱-۲ دقیقه آدرسی مثل این می‌گیری:
   `https://playverse-server-xxxx.onrender.com`
6. در بازی: **تنظیمات ← سرور بازی ← آدرس را وارد کن ← تست ← ذخیره**
7. حالا با اکانت **mrshash** ثبت‌نام کن → خودکار ادمین می‌شوی 👑

> ⚠️ پلن رایگان Render بعد از ۱۵ دقیقه بی‌استفاده خواب می‌شود؛ اولین ورود چند ثانیه طول می‌کشد تا بیدار شود.

## راه ۲ — Railway / Fly.io / هر هاست Node

مثلاً روی Railway: **New Project ← Deploy from GitHub repo** و Root Directory = `server`. بقیه همان.

## راه ۳ — روی کامپیوتر خودت

```bash
cd server
npm install
npm start          # روی http://localhost:3010 بالا می‌آید
```
برای اینکه دوستانت وصل شوند، با `ngrok http 3010` آدرس عمومی بگیر.

## نکته‌های مهم

- **ادمین:** هر اکانتی با نام کاربری `mrshash` ساخته شود خودکار ادمین است. (قابل تغییر با متغیر محیطی `ADMIN_USERNAME`)
- **داده‌ها** در `server/data/db.json` ذخیره می‌شوند؛ بک‌آپ گرفتن = کپی کردن همین فایل.
- اگر سرور خاموش باشد، بازی خودکار در «حالت محلی» کار می‌کند و هیچ‌چیز خراب نمی‌شود.
- همه‌ی پاسخ‌های API با CORS باز هستند تا از دامنه‌ی GitHub Pages قابل استفاده باشند.
